## 🌟 Overview & Architecture

This portfolio website is designed and engineered to elite production standards. It features a dark-mode-first aesthetic (`#0B0F17`), subtle 3D interactive graphics built directly with Three.js/WebGL, responsive real-time telemetry streaming simulators, and multi-tier architectural case studies.

### Core Tech Stack
- **Framework:** Next.js 16 (App Router) with React 19 & TypeScript
- **Styling:** Tailwind CSS v4 + Custom Glassmorphism System
- **3D & Canvas:** Three.js / WebGL hardware-accelerated interactive node constellation with cursor parallax & gyro physics
- **Animation & Motion:** Framer Motion micro-interactions & canvas-confetti feedback
- **Icons:** Lucide-React & Custom SVG Monograms
- **SEO & Performance:** Pre-configured OpenGraph metadata, JSON-LD Schema (`Person` / `SoftwareEngineer`), dynamic sitemap readiness, and sub-120ms latency optimization.
